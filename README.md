# Проект: Система фильтрации и аналитики данных для агрономов

## Описание проекта

Наш проект представляет собой решение для автоматизации обработки и анализа данных, поступающих от агрономов. Система позволяет сократить время выполнения процессов в 20-30 раз и снизить затраты в 7-10 раз за текущий год. Основная цель проекта — минимизировать потери аграрных компаний, которые могут достигать до 25% потенциального дохода из-за неэффективного управления ресурсами и ручного анализа данных.

### Основные функции:
1. **Извлечение данных из Telegram-чатов**: Автоматическое извлечение и обработка сообщений агрономов.
2. **Прогнозирование погодных условий**: Использование данных Яндекс.Погоды и OpenNewsApi для прогнозирования климатических условий и возможных аварий.
3. **Аналитика и отчеты**: Генерация аналитических отчетов с использованием графиков, системы узлов и графика Ганта.
4. **Создание Excel-файлов**: Автоматическое создание Excel-файлов после обработки данных с помощью LLM.

## Системные требования

Для успешного внедрения и работы системы необходимы следующие минимальные системные требования:

- **SSD**: 256 ГБ
- **Оперативная память**: 32 ГБ
- **Видеопамять**: 16 ГБ

## Преимущества внедрения

1. **Сокращение потерь**: Использование системы позволяет сократить потери до 15-20% за счет эффективного управления ресурсами и оперативного реагирования на изменения погодных условий.
2. **Увеличение прибыли**: Компании с высококачественной аналитикой могут увеличить свою прибыль на 10-30%.
3. **Уникальность решения**: Интеграция с OpenNewsApi для получения информации о возможных авариях делает наше решение уникальным и позволяет заранее планировать меры по предотвращению убытков.
